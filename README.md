`Flutter` `Riverpod` `Clean Architecture` · [**Live Demo →**](https://smh1s1n.github.io/dental-profile/)

### 🐍 [Brick Snake — 1100 Edition](https://github.com/smh1s1n/brick-snake)
A faithful, 100% feature-complete recreation of Nokia 1100's Snake II — 5 authentic mazes, 9 speed levels, dot-matrix LCD shader, and a clickable LED torch.

`Flutter` `Riverpod` `DDD` · [**Play Online →**](https://smh1s1n.github.io/brick-snake/)

### 🛡️ [ReelsGuard — Anti-Doomscroll Monitor](https://github.com/smh1s1n/reels-count)
Privacy-first short-video tracker for Instagram Reels, TikTok and YouTube Shorts. Detects reels via Android `AccessibilityService`, measures dwell time, and triggers outside-the-app mindful break overlays.

`Flutter` `Kotlin` `Foreground Service` `Neumorphic UI` `100% On-device`

### 🏋️ [Aegis Fitness AI — GenUI Chat](https://github.com/smh1s1n/fitness_genui_chat)
Conversational fitness coach that renders fully interactive Flutter widgets (water tracker, workout logger, macro rings, rest timer, BMI calculator, trend charts) from Gemini structured responses.

`Flutter` `Gemini API` `GenUI` `Riverpod`

### 👁️ [IrisFlow — Eye Health Focus Timer](https://github.com/smh1s1n/irisflow)
Pomodoro-style focus app that monitors eye strain in real time using ML Kit eye-aspect-ratio detection and Gemini-powered fatigue analysis, adapting the UI when strain is detected.

`Flutter` `ML Kit` `Gemini` `Drift` `Riverpod`
